# Wish Study ♧

スマホ向けの勉強管理Webアプリです。

## GitHub Pagesで公開する方法
1. GitHubで新しいPublicリポジトリを作成します（例：`wish-study`）。
2. ZIPを解凍し、中にある `index.html`、`manifest.json`、`sw.js` をリポジトリの一番上にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、Branchを `main`、フォルダを `/(root)` にして **Save**。
5. 数分待ち、表示される `https://ユーザー名.github.io/wish-study/` を開きます。

## iPhoneのホーム画面に追加
1. 公開したURLをSafariで開きます。
2. 共有ボタンをタップします。
3. **ホーム画面に追加** を選び、追加します。

## 保存について
勉強内容と時間は、開いているブラウザの `localStorage` に日付ごとに保存されます。同じ端末・同じブラウザで使ってください。ブラウザのWebサイトデータを消すと記録も消える場合があります。
サービスワーカーを含みますが、オフラインでの初回起動には、最初にインターネット接続で一度開く必要があります。

## フォント
851手書き雑フォントは標準では内蔵していません。端末にインストールされている場合は優先して使用し、ない場合は標準の日本語フォントにフォールバックします。
